# Fibonacci Clock

황금 나선(피보나치 나선)이 회전하며 시각을 가리키는 시계. 빌드 없이 `index.html` 하나로 동작한다.

## 읽는 법

- 시·분·초 다이얼마다 황금 나선 r = e^(bθ) (90°마다 ×φ)이 한 주기(12시간 / 60분 / 60초)에 한 바퀴 돈다.
- 나선과 세로축의 교차점이 반 바퀴마다 ×φ² 바깥으로 이동하며, 위쪽 축(눈금 1–6)과 아래쪽 축(눈금 7–12)을 번갈아 지난다.
- 눈금은 한 칸마다 φ^(1/3) 배 간격으로 놓였고, 각 눈금의 회색 호는 그 값을 정확히 가리킬 때 나선이 놓이는 자리다.
- 현재 구간은 주황색, 교차점은 파란 빛점으로 표시된다.

## 조작

- **Live / ×60 / ×720** — 시간 배속
- **Squares** — 나선과 함께 도는 황금 사각형 표시
